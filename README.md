# StudyCircle

StudyCircle is a collaborative learning and productivity platform designed to help students stay focused, learn effectively, and maintain healthy digital habits.

The application combines educational tools, self-growth features, and productivity tracking into one platform.

---

## Features

- User Authentication (Login/Register)
- Recommended Study Content
- Quiz Module
- Journal System
- Screen Time Tracking
- Productivity Insights
- Notifications & Reminders
- Responsive User Interface
- Secure Backend APIs

---

## Installation

### Clone Repository

```bash
git clone https://github.com/garima26480/StudyCircle.git
```

### Move Into Project Folder

```bash
cd StudyCircle
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside backend folder and add:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```
